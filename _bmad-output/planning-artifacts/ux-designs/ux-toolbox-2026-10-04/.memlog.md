- (decision) Aesthetic direction: minimal, modern, boxy, monochrome (black, white, restrained shades of gray), no gradients, high contrast and distinct component affordances
- (decision) GUI framework: Slint
- (requirement) Component library must be compatible with Slint, highly configurable and customizable for boxy monochrome styling
- (note) Evaluated Slint component libraries: slintcn, std-widgets, SurrealismUI, Material Components, slint-ui-system, vivi_ui
- (decision) Adopted slintcn as the component library foundation with 0px boxy borders and full in-repo code ownership
- (decision) Working mode: Coaching path
- (event) Rendered 4 boxy monochrome color themes in .working/color-themes-1.html
- (decision) Default theme: Industrial Graphite (canvas #141618, surface #1E2124, border #32383E, text #E2E8F0)
- (decision) Typography: All-monospace brutalism (cyberdeck / terminal feel across headers, labels, buttons, inputs)
- (decision) Shell layout: Model A Dual-Pane Workbench (left sidebar tool tree, right active workspace, global Omni-Bar Super+Shift+T)
- (decision) Theme system: Omarchy-inspired palette switching via Slint global Theme tokens, maintaining strict 0px boxy monospace layout across all themes
- (event) Generated 10 Omarchy themes showcase in .working/omarchy-themes.html with live interactive theme switcher and dual-pane workbench preview
- (feedback) User critique: UI has too many details and feels overwhelming. Hate visual clutter. Maintain exact Omarchy design language (themes, boxy 0px, monospace), but radically simplify layout to minimal essential elements so users instantly know what to do.
- (decision) Aesthetic principle: Radical reduction. Strip non-essential badges, headers, and secondary clutter. Focus each screen on one single primary task with generous negative space and clear affordances.
- (event) Created radically simplified minimal-workbench.html with zero clutter, 1-second task clarity, generous breathing room, and 10 Omarchy themes
- (event) Promoted minimal-workbench.html and omarchy-themes.html to mockups/ as visual reference
- (event) spines finalized
- (decision) Tool strategy: Toolbox acts as a modern unified GUI + CLI wrapper orchestrating best-in-class Linux CLI tools under the hood. Detect host installations via PATH, and provide automated installation/fetching when users enable tools.
- (decision) PDF engine: Standardize on qpdf as the CLI engine for all PDF operations (repair, merge, split, compress, encryption)
- (decision) Image engine: Standardize on ImageMagick (magick) as the Linux CLI engine for image conversion, SIMD resizing, and format transcoding
- (decision) Archive engine: Standardize on 7-Zip (7z) as the Linux CLI engine for multi-format extraction (.zip, .tar.gz, .tar.xz, .7z) and AES-256 archive packaging
- (decision) JSON engine: Standardize on pure Rust serde_json in tb-core for in-memory formatting, minification, and line/column syntax error diagnostics with native tb dev json commands
- (decision) Dependency strategy: Hybrid Smart Resolver in tb-deps - probes host PATH first. If missing, offers 1-click zero-sudo static download to ~/.toolbox/deps/ with option to copy host distro command (pacman/apt/dnf)
