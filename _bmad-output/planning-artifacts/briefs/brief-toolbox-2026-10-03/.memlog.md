- (event) User selected Coaching Path; initiating step-by-step discovery starting with The Problem.
- (insight) User friction sequence: Look for pre-installed tool -> find none -> resort to Google -> land on untrusted web converter -> face privacy anxiety over unverifiable deletion claims.
- (insight) Worst-case consequence identified: Sensitive PII/IP stolen, sold to unauthorized AI training data sets, or exposed in data breaches/cybersecurity attacks.
- (decision) Interaction SLA: Global hotkey trigger, sub-2-second launch, auto-focused fuzzy search, full optional keyboard navigation alongside drag-and-drop.
- (idea) UX Reassurance Hook: Clear post-completion banner: 'Processed 100% locally — your data never left your machine' to reinforce privacy and trust.
- (insight) Target Market & Value Moat: Rising Linux desktop adoption creates demand for friction-free utilities; value is orchestration and sane defaults over battle-tested engines (FFmpeg, Poppler, Tesseract), not reinventing low-level algorithms.
- (decision) Scope Boundaries for v1: Strict exclusion of AI/LLM, OCR, background removal, video editing timelines, and custom themes; focus strictly on battle-tested libraries for file conversions/compressions and full DevToys dev utility parity.
- (decision) Release Strategy: Iterative staged releases (v0.1 -> v0.2 -> v1.0) prioritizing zero-friction libraries and rock-solid reliability over raw feature count.
- (decision) Roadmap Definition: Multi-stage versioning spanning v0.1 (CLI devtools) -> v0.2 (Image/PDF) -> v0.3 (Media & Everyday) -> v0.4 (Slint GUI & Omni-Bar) -> v0.5 (Keyboard UX & Pipes) -> v1.0 (Packaging & Extensibility) -> v1.5 (Heavy OCR) -> v2.0 (Local AI).
- (event) Product Brief finalized and published to brief.md and PRODUCT-BRIEF.md with comprehensive 8-stage roadmap, Slint UI stack, and strict v1.0 scope boundaries.
- (change) Updated brief with on-demand zero-sudo dependency architecture, Omni-Bar download-and-run discovery, and explicit manual storage dashboard.
