- (idea by user) On-demand extension enablement: Core app bundles UI definitions for all tools, but heavy dependencies (e.g. FFmpeg) install only when user clicks Enable / first uses the tool.
- (idea by user) Orphan dependency garbage collection: When an extension is disabled, uninstall its dependencies if no other active extension references them.
- (technique) started TRIZ Contradiction Analysis: Tiny 15MB initial footprint vs. zero-sudo battery-included power across distros.
- (idea by coach) Three-tier dependency resolution: 1. Host Probe (use existing system binary if present -> 0MB download), 2. Flatpak runtime extension if sandboxed, 3. User-space static download into ~/.toolbox/deps/ with zero sudo.
- (decision) UX Rule: Never hide tools in search; uninstalled tools appear in Omni-Bar with inline '[Enter to Download & Run]' action with zero manual terminal instructions.
- (idea) Cross-Platform Dependency Engine: Detect OS/Arch (Linux x86_64/ARM, Mac Silicon, Windows) and fetch pre-built standalone static binaries to user-space cache directory with zero OS package manager involvement.
- (decision) Storage Lifecycle Policy: No automated background deletion. A dedicated 'Storage & Engines' dashboard displays disk footprint and 'Last Used' timestamp per tool; removal is strictly explicit and user-initiated to prevent broken offline workflows.
